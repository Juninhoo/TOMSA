# TOMSA 2026 — Ficheiros Fonte e Recursos Base do Projeto

Esta pasta arquiva os recursos, protótipos exploratórios, guiões preliminares e notas iniciais que serviram de **base de inspiração e desenvolvimento** para o projeto **TOMSA 2026**.

---

## 🗂️ Conteúdo da Pasta `base_sources/`

1. **`code/`**:
   - `missions.py`: Gerador de missões sintéticas e protótipo inicial do analisador de odometria em formato tabular.
   - `test_uwmath.py`: Testes matemáticos preliminares de rotação SO(3), quaterniões e projeções de câmara.

2. **`vista_primeira_pessoa/`**:
   - Módulo protótipo C++ / Python desenvolvido para experimentação de renderização POV e projeções de perspetiva com matriz de calibração intrínseca.

3. **`trajectories/`**:
   - Visualizador HTML estático autónomo (`trajectories.html`), memorial descritivo inicial em PDF (`trajectory_viewer_math.pdf`) e arquivo ZIP original (`uwv_project.zip`).

4. **`scratch/`**:
   - Scripts auxiliares de reconstrução de cadernos Jupyter e rascunhos de injeção JavaScript (`dashboard_script.js`).

5. **`draft_notebooks/`**:
   - Versões preliminares e modelos de cadernos Jupyter exploratórios desenvolvidos pelos vários elementos do grupo durante o processo de prototipagem.

6. **`initial_notes/`**:
   - `projectidea`: Brainstorming inicial e estruturação de requisitos.
   - `template`: Modelo fornecido pela unidade curricular para formatação das entregas.
   - `new_1.txt`: Anotações preliminares sobre critérios de avaliação e referenciais geodésicos.
